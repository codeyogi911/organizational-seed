# Process: handle uncovered work

## Outcome

Work that no active Process covers reaches the smallest safe result permitted
by existing Authority. The organization preserves a draft, gap, or Lesson only
when it would help future work; nothing becomes reusable Authority by accident.

## When to use

Use only after the Process index and a repository search find no active Process
whose Outcome fits the request. A missing Process is a normal growth signal,
not permission to borrow boundaries from similar work.

## Boundaries

- Perform only what existing Authority permits; every external effect still
  requires its ordinary approval.
- A draft under `work/process-drafts/` is Working State. It grants no reusable
  Authority and may not be listed as active.
- Do not create a Process merely because one unusual Task occurred.
- Creating any active Standing Knowledge uses
  [change Standing Knowledge](change-standing-knowledge.md).

## Evidence and approvals

Read the Process index, the closest Processes, and relevant Records before
concluding the work is uncovered. Cite the sources behind material claims.
Obtain the same one-time approvals the actual effect would require if an active
Process existed; this Process supplies no extra Authority.

## Steps

1. Search by the requested outcome, not a guessed Process name.
2. Define the smallest useful result existing Authority allows.
3. Perform it, or stop with the exact missing evidence, approval, or capability.
4. Record the verified result and any external-effect receipt.
5. If recurrence is plausible, leave a small draft Process. Otherwise record a
   Lesson or gap only when it would help a future reader.
6. Route any candidate for active use through Change Standing Knowledge.

## Done when

- The request reached a verified result, honest no-op, or named blocker.
- No effect exceeded existing Authority.
- Useful missing knowledge is visible as a draft, gap, or Lesson, or the result
  says why no durable residue would help.
- Nothing created during the performance is presented as active Authority.

## Failure and recovery

The Task and verified effect receipts are the recovery point. On resume,
recheck current external facts and Authority before retrying. Never repeat an
uncertain external effect. A weak draft remains Working State until a separate
governed change makes it active.
