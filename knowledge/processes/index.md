# Processes

This is a replaceable discovery projection. Each row repeats the linked
Process title and `description` exactly; `tools/doctor` rejects drift. Open only
the Process whose outcome fits the intended work.

| Process | Use it when |
|---|---|
| [handle uncovered work](handle-uncovered-work.md) | Reach the smallest safe result when no active Process fits, then preserve only the reusable residue. |
| [review Lessons](review-lessons.md) | Decide whether pending Lessons should be absorbed, kept, rerouted, or closed. |
| [change Standing Knowledge](change-standing-knowledge.md) | Create, correct, improve, merge, rename, or retire knowledge that future work must follow. |
| [weekly review (example)](example-weekly-review.md) | Adapt this worked example into an Instance's first recurring Process. |

[`_contract.md`](_contract.md) defines Process shape and naming. It is not a
performable Process.
